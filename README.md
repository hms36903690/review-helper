# 쿠팡 리뷰 도우미 (체험단·내돈내산)

상품명과 내 사용 경험 메모를 넣으면, Claude가 인터넷에서 상품 정보(스펙·가격대·다른 구매자 평)를 찾아
장점·단점이 들어간 리뷰 초안을 써 주는 웹앱입니다. `index.html` 파일 하나로 되어 있습니다.

## 사용 방법

1. 앱을 열고 **🔑 Claude API 키 설정**에 키를 넣고 저장합니다(console.anthropic.com 에서 발급, 사용한 만큼 요금).
   키는 그 기기 브라우저에만 저장됩니다.
2. 상품명, 직접 써 보고 느낀 점(짧은 메모)을 적고 **리뷰 만들기**를 누릅니다.
3. 노란색 `[직접 확인: …]` 빈칸을 내 경험으로 채우거나 지우고, "올리기 전에 확인할 점"을 확인한 뒤 복사해서 올립니다.

## 기능

- **한 개 쓰기**: 상품명 + 메모 → 리뷰 1개. "AI가 물어봐 주기"를 누르면 써 본 사람만 답할 수 있는 질문 4~5개를 받아 답을 메모에 보탭니다.
- **여러 개 한꺼번에**: 한 줄에 `상품명 / 메모`씩 최대 20개를 차례로 씁니다(밀린 리뷰 정리용).
- **추가 요청**: "아기 키우는 집 입장에서"처럼 AI에게 따로 부탁할 내용.
- **체험단 규칙 표시**: 글자수 200자 이상(700자 이내 권장), 상품 사진 필수(7장 이내 권장), 초대일 포함 14일 이내 작성.
  초대일을 넣으면 마감일과 D-day를 보여 주고, 결과에 글자수 통과 여부와 찍을 사진 목록이 나옵니다.
- **글 구성**: 이야기형 / 소제목형 / 구간형(구매 이유·사용 후기·아쉬운 점·총평), **첫인사**(예: "안녕하세요~ ○○입니다"), 말투에 "수다스럽게(^^ ~ ㅎㅎ)" 추가.
  도움됐어요를 많이 받은 실제 리뷰의 특징(구매 이유로 시작, 옵션 고민, 사용 순서, 숫자, 사진 언급, 해결 팁이 있는 아쉬운 점, 추천 대상)을 따라 씁니다.
- **상품 이미지**: 상품명 칸 옆 네모에 쿠팡 상품 사진이나 상품 화면 캡처를 넣으면(고르기·끌어다 놓기·상품명 칸에서 Ctrl+V) 거기서 상품명·옵션·스펙을 알아냅니다. 상품명은 비워도 됩니다.
- **내가 찍은 사진**: 최대 7장. 사진에 보이는 색상·구성품·크기 등을 리뷰에 반영합니다.
- **작성 기록**: 최근 50개를 이 기기에 저장, 다시 복사·삭제.

쿠팡에 자동으로 로그인하거나 자동으로 올리는 기능은 넣지 않았습니다(쿠팡 이용약관상 외부 프로그램 접근 금지). 복사해서 직접 올립니다.

## 원칙

- 사용 경험은 사용자가 적은 메모로만 씁니다. 없는 경험은 지어내지 않고 빈칸으로 남깁니다.
- 단점은 2개 이상 구체적으로 씁니다.
- 끝에 체험단 제공 문구를 넣는 옵션이 기본으로 켜져 있습니다(공정위 표시 지침).

## PC 바탕화면에 설치

Chrome이나 Edge로 위 주소를 열고, 화면 맨 위 **💻 설치하기** 버튼(또는 주소창 오른쪽 끝의 설치 아이콘)을 누르면
바탕화면과 시작 메뉴에 아이콘이 생기고, 따로 창이 뜨는 프로그램처럼 쓸 수 있습니다.
