# 쿠팡 리뷰 도우미 (체험단·내돈내산)

상품명과 내 사용 경험 메모를 넣으면, Claude가 인터넷에서 상품 정보(스펙·가격대·다른 구매자 평)를 찾아
장점·단점이 들어간 리뷰 초안을 써 주는 웹앱입니다. `index.html` 파일 하나로 되어 있습니다.

## 사용 방법

1. 앱을 열고 **🔑 Claude API 키 설정**에 키를 넣고 저장합니다(console.anthropic.com 에서 발급, 사용한 만큼 요금).
   키는 그 기기 브라우저에만 저장됩니다.
2. 상품명, 직접 써 보고 느낀 점(짧은 메모)을 적고 **리뷰 만들기**를 누릅니다.
3. 노란색 `[직접 확인: …]` 빈칸을 내 경험으로 채우거나 지우고, "올리기 전에 확인할 점"을 확인한 뒤 복사해서 올립니다.

## 원칙

- 사용 경험은 사용자가 적은 메모로만 씁니다. 없는 경험은 지어내지 않고 빈칸으로 남깁니다.
- 단점은 2개 이상 구체적으로 씁니다.
- 끝에 체험단 제공 문구를 넣는 옵션이 기본으로 켜져 있습니다(공정위 표시 지침).

## 휴대폰에서 쓰기 (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → 브랜치를 고르고 `/ (root)` → Save.
몇 분 뒤 `https://hms36903690.github.io/review-helper/` 주소로 열 수 있습니다.

## PC 바탕화면에 설치

Chrome이나 Edge로 위 주소를 열고, 화면 맨 위 **💻 설치하기** 버튼(또는 주소창 오른쪽 끝의 설치 아이콘)을 누르면
바탕화면과 시작 메뉴에 아이콘이 생기고, 따로 창이 뜨는 프로그램처럼 쓸 수 있습니다.
